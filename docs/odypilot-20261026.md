## TSFDOM relationship

Our original fix and Patrick's current branch use the same sunnypilot plain-artifact
approach, not different competing fixes. This update replaces our older model stack
with his newer coherent stack and keeps the missing `ChestnutRetry` registration we
had added. See [the TSFDOM compatibility history](ody-test-tsfdom.md).
